二、关键数据流

sequenceDiagram
    participant U as 👤 用户
    participant D as 🧠 DSH :3080
    participant A as 📊 OpenAlice
    participant C as 🤖 claude CLI
    participant M as 🌐 模型服务
    U->>D: 打开 DSH，点「◈ OpenAlice」
    D->>A: 插件加载 iframe(5173)
    A-->>U: 显示交易工作台界面
    U->>A: 在 Chat 提问
    A->>C: 拉起 claude CLI（注入凭证+模型）
    C->>M: 调用模型
    M-->>C: 返回回答
    C-->>A: 结果写回工作区 / Inbox
    A-->>U: 显示对话 / 报告
